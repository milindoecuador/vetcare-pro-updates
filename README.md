# VetCare Pro — actualizaciones

Canal oficial de distribuciones firmadas de VetCare Pro.

Cierre VetCare y ejecute Actualizar_VetCare.bat para comprobar la última versión estable. Cada release contiene un ZIP y update-manifest.json firmado con Ed25519. La clave pública viene incluida en la aplicación.

Las distribuciones no incluyen pacientes, bases de datos, certificados, credenciales ni claves privadas. Los comprobantes del POS son internos; no acreditan autorización SRI.

Este canal distribuye el programa Python; requiere Python 3 con Tkinter e instalación de requirements.txt. No es un instalador EXE.
